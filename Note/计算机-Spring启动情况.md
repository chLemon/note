# 确认 Spring 启动情况的日志

## 启动成功关键字

```shell
2026-05-26T17:05:53.123+08:00  INFO 12345 --- [main] c.e.demo.DemoApplication : Started DemoApplication in 2.345 seconds (process running for 2.89)
```

关键词：`Started [ApplicationClassName] in [X] seconds`。

## 启动失败关键字

```shell
***************************
APPLICATION FAILED TO START
***************************
```
